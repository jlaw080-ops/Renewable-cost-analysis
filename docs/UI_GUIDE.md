# UI 디자인 가이드

## 디자인 원칙
1. **수치가 주인공이다.** 표·차트가 화면의 중심. 장식은 최소화한다.
2. **엔지니어링 검토 도구 톤.** 화려함보다 정확함·가독성. 한눈에 비교 가능하게.
3. **절감/생산 = 긍정 수치는 한 가지 액센트(그린)로만 강조.** 색을 남발하지 않는다.
4. **입력→결과 흐름이 분명해야 한다.** 탭으로 단계를 구분하고 현재 위치를 늘 표시.

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() (glass morphism) | AI 템플릿의 가장 흔한 징후 |
| gradient-text (제목 그라데이션) | AI 생성 SaaS 랜딩의 1번 특징 |
| box-shadow 글로우/네온 애니메이션 | AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드 동일한 rounded-2xl | 균일한 둥근 모서리 = 템플릿 느낌 |
| 배경 gradient orb / blob | 모든 AI 랜딩에 있는 장식 |
| 의미 없는 이모지 헤더 | 엔지니어링 도구에 부적합 |

## 색상
- 배경: 흰색(#FFFFFF) / 섹션 구분은 아주 옅은 회색(#F7F7F8)
- 본문 텍스트: 진회색(#1F2328) / 보조 텍스트: 중간회색(#6B7280)
- 테두리·구분선: 옅은 회색(#E5E7EB)
- **액센트(절감·생산·긍정)**: 차분한 그린(#2F855A 계열)
- 경고/비용: 무채색 또는 절제된 적색(#B91C1C), 남용 금지

## 컴포넌트
- **카드**: 1px 회색 테두리 + 작은 라운드(rounded-md). 그림자는 거의 없거나 매우 약하게.
- **버튼**: 기본은 진회색/검정 배경의 솔리드, 보조는 테두리만(outline). 그라데이션·글로우 금지.
- **입력 필드**: 라벨은 필드 위, 단위(m², kW, h)는 필드 우측에 회색으로 표기.
- **결과 표(테이블)**: 숫자는 우측 정렬 + 고정폭 글꼴, 천단위 콤마, 합계 행은 굵게. 월별 12행 + 연간 합계 행 패턴.
- **차트(Recharts)**: 막대/선 위주. 절감액·현금흐름은 막대, 누적현금흐름은 선. 색은 액센트 1~2색만.

## 레이아웃
- 최대 콘텐츠 너비 약 1100px, 가운데 정렬.
- 탭: 입력 → 소비량/요금 → 신재생 생산·절감 → 경제성 → 리포트.
- 입력과 결과는 좌우 또는 상하로 명확히 구분. 결과는 표 먼저, 차트 보조.

## 타이포그래피
- 제목: 시스템 산세리프, 적당히 굵게(과한 볼드 금지).
- 본문: 14~16px, 줄간격 넉넉히.
- 숫자/단위: 고정폭(monospace) 폰트로 정렬감 확보.

## 애니메이션
- 허용: 탭 전환 시 짧은 페이드(150ms 이내), 버튼 hover 색 변화.
- 그 외(글로우, 떠다니는 요소, 자동 재생 모션 등) **모두 금지**.
