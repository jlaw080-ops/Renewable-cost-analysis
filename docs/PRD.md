# PRD: 신재생에너지 생산량·경제성 검토 앱

> 권장 레포명: `renewable-feasibility`

## 목표
임의의 건축물에 대해 (1) 전력 소비량과 전기요금을 예측하고, (2) 신재생에너지(연료전지·태양광) 도입 시 연간 절감액과 경제성(NPV·IRR·투자회수기간)을 자동 산출하는 검토 도구.

## 사용자
건축설비·신재생에너지 엔지니어. 기획·VE 단계에서 신재생 도입 효과를 빠르게 개략 검토하려는 1인 사용자(로그인 없음, 검토안 저장은 가능).

## 핵심 기능
1. **건물 전력·가스 소비량 예측** — 용도 선택(복수) + 용도별 연면적 입력 → 용도라이브러리의 단위면적당 전력·도시가스 원단위로 연간 전력·가스 사용량 산출
2. **에너지요금 기준선 계산** — 전기요금(요금제 선택: 갑 계절별 / 을 시간대별, 계약전력 기준) + 가스요금(일반용 도시가스) → 연간 전기·가스 기준선
3. **신재생 생산량 계산**
   - 연료전지: 이전 앱 로직 재사용(전력·열·가스)
   - 태양광: 용량·일간 발전시간 입력 → 발전량 산출
4. **절감액 산출** — 전력요금 절감과 가스요금(열생산) 절감을 **분리 표시** + 총 절감액·절감률
5. **경제성 평가** — 투자비·유지보수비·분석기간·할인율 입력 → 순현금흐름, 누적현금흐름, 단순회수기간, NPV, IRR, B/C
6. **결과 출력 및 저장** — 화면 테이블/차트 + PDF 다운로드 + 검토안 DB 저장/불러오기

> 모든 계산 로직은 `docs/calculation-formulas.md`를 단일 기준으로 한다.

## MVP 제외 사항
- **지열** — 추후 별도 모듈로 추가.
- **AI 검토 의견(Gemini 코멘트)** — MVP에서는 넣지 않음.
- **잉여 발전 판매 보정** — 생산량이 소비량을 초과해도 단가 환산만 함.
- **다중 사용자/인증** — 로그인·권한 없음.

## 디자인
- 엔지니어링 검토 도구 톤: 数表·차트 중심, 차분하고 정보 밀도 높은 화면.
- 절감/생산 등 긍정 수치는 그린 계열 액센트 1색으로 강조, 나머지는 중립 회색조.
- AI 템플릿 느낌(보라/인디고, glass morphism, gradient orb 등) 배제 — 상세는 `docs/UI_GUIDE.md`.
- 탭 흐름: 입력 → 소비량/요금 → 신재생 생산·절감 → 경제성 → 리포트.
