# 계산 수식 정의서 (calculation-formulas.md)

> **버전**: v2.2 (건물 가스 소비/가스요금 기준선 추가 — 전기·가스 대칭 비교)
> **대상 앱**: 신재생에너지 에너지 생산량 + 경제성 검토 앱
> **연료전지 계산 출처**: 이전 "연료전지 경제성 평가 앱" 로직 재사용 (Input1/2, output1~4, 라이브러리 형식 그대로)

> ⚠️ **이 문서는 앱 계산 로직의 단일 원본(Single Source of Truth)입니다.**
> - 코드의 모든 계산 결과는 반드시 이 문서와 일치해야 합니다.
> - 수정이 필요하면 **사람이 먼저 이 문서를 고친 뒤** 코드가 따라가게 합니다.
> - 연료전지(F)·경제성(G)은 이전 앱 구현과 결과가 일치해야 합니다(부가세·기금·ROI 정의 등 확인).

## 0. 입력값 / 라이브러리 (실제 형식)

### 사용자 입력값
| 항목 | 단위 | 비고 |
|------|------|------|
| 건물 용도[] + 연면적_i | m² | 복수 선택 |
| 요금제 선택 | — | 전기요금라이브러리.요금제목록 중 선택 (기본: 일반용(갑)Ⅰ 고압A 선택Ⅱ) |
| 계약전력 | kW | 기본요금용 (직접 입력) |
| 일간_사용시간 | h | 건물 하루 운전시간 (**시간대별 요금제일 때만 사용**) |
| 운전 시작 시각 | 시 | **09:00 고정** (시간대별 요금제일 때만) |
| 연간운전유형 | — | 월별가동일라이브러리 키 선택 (365일가동/주말일부가동/평일가동/학기중가동) |
| 태양광_용량 / 태양광_일간발전시간 | kW / h | |
| 태양광_kW당설치단가 / kW당유지비 | 원/kW · 원/kW·yr | 경제성용 |
| 연료전지 sets[] | — | Input1 형식 (모델+설치수량) |
| 분석기간 / 할인율 | 년 / % | 경제성용 (기본 20년) |

### 라이브러리 (첨부 파일 형식 그대로)
| 파일 | 형식 |
|------|------|
| `용도라이브러리.json` | `{ 단위, 데이터:[{용도, 전력원단위, 도시가스원단위}] }` — 전기·도시가스 모두 보유 (Mcal→kWh 환산) |
| `전기요금라이브러리.json` | `{ 요금제목록:[...], 계절구분, 기본선택 }` — 각 요금제는 `방식="계절별"`(일반용 갑: 계절단가) 또는 `방식="시간대별"`(일반용 을: 시간대구분 + 월별 경/중/최) |
| `가스요금라이브러리.json` | `[{구분, 단가_원per_kW}]` — "연료전지전용"=4.01154, "일반용(영업1) 도시가스 요금"=5.3072 |
| `월별가동일라이브러리.json` | `{ 운전유형:{연간가동일, 월별가동일[12]} }` |
| `연료전지제품라이브러리.json` | `[{형식,제조사,모델명,정격발전용량_kW,열생산용량_kW,가스소비량_kW,발전효율,열회수효율,kW당설치단가,kW당연간유지비용}]` |

### 상수 (이전 앱 기준)
- 부가세 계수 = `1.1`, 전력기금 계수 = `1.032`
- ⚠️ 이전 앱에 부가세/기금을 **가산(×1.1×1.032)** 한 곳과 **차감(×0.9×0.968)** 한 흔적이 둘 다 있음 → 구현 시 이전 앱 실제 코드와 **반드시 일치**시킬 것. 본 문서는 절감(회피비용) 관점에서 **가산**으로 표기.

## A. 건물 에너지 소비량 (기준선의 출발점)

### A-1. 전력 소비량
```
연간_전력사용량_i (kWh) = 연면적_i (m²) × 전력원단위_i (kWh/m²·yr)
총_연간_전력사용량 (kWh) = Σ(용도 i) 연간_전력사용량_i
```
- 전력원단위_i : 용도라이브러리.데이터[용도].전력원단위

### A-2. 도시가스 소비량
```
연간_가스사용량_i (kWh) = 연면적_i (m²) × 도시가스원단위_i (kWh/m²·yr)
총_연간_가스사용량 (kWh) = Σ(용도 i) 연간_가스사용량_i
```
- 도시가스원단위_i : 용도라이브러리.데이터[용도].도시가스원단위

## B. 연간 전기요금 = 기준선 (신재생 도입 전)

> 요금제 = 사용자 선택 (전기요금라이브러리.요금제목록). 계약전력 300kW 미만은 보통 **일반용(갑)Ⅰ**(계절별), 그 이상은 **일반용(을)**(시간대별).

### B-1. 기본요금
```
연간_기본요금 (원) = 계약전력(kW) × 요금제.기본요금_원per_kW × 12
```

### B-2. 사용량요금 (요금제 '방식'에 따라 분기)
```
공통: 월별 사용량 분배
월별가동일[월] = 월별가동일라이브러리[연간운전유형].월별가동일[월]
연간_가동일수  = 월별가동일라이브러리[연간운전유형].연간가동일
월별_사용량(kWh) = 총_연간_전력사용량 × 월별가동일[월] / 연간_가동일수
```

**[방식 = "계절별"]  예: 일반용(갑)Ⅰ — 시간대 배분 불필요**
```
월_계절 = 전기요금라이브러리.계절구분에서 (월)이 속한 계절   (여름철/봄가을철/겨울철)
월_단가 = 요금제.계절단가[월_계절]
월별_사용량요금 = 월별_사용량 × 월_단가
연간_사용량요금 = Σ(1~12월) 월별_사용량요금
   · 이 방식은 '일간_사용시간'을 쓰지 않는다.
```

**[방식 = "시간대별"]  예: 일반용(을) — 09:00 시작 기준 경/중/최 배분**
```
① 운전시각집합 = { (9 + k) mod 24 | k = 0 .. 일간_사용시간 − 1 }   (정수 시간; ≥24면 0~23 전체)
   각 운전시각을 요금제.시간대구분으로 경/중/최부하에 매핑
   경부하_시간수 / 중간부하_시간수 / 최대부하_시간수  (합 = 일간_사용시간)

② 월별 시간대 사용량 = 월별_사용량 × (시간대_시간수 / 일간_사용시간)

③ 월별_사용량요금 =
     경부하_사용량(월)   × 요금제.데이터[월].경부하
   + 중간부하_사용량(월) × 요금제.데이터[월].중간부하
   + 최대부하_사용량(월) × 요금제.데이터[월].최대부하
연간_사용량요금 = Σ(1~12월) 월별_사용량요금
```

### B-3. 전기요금 기준선 합계
```
연간_전기요금(기준선) = (연간_기본요금 + 연간_사용량요금) × 1.1 × 1.032
```

### B-4. 가스요금 기준선
```
연간_가스요금(기준선) = 총_연간_가스사용량 × 가스요금["일반용(영업1) 도시가스 요금"].단가_원per_kW
   · 가스 절감(D)과 같은 단가 기준 → 부가세 미적용(대칭 비교 위해 D와 동일 처리)
```

### B-5. 총 에너지요금 기준선
```
연간_총에너지요금(기준선) = 연간_전기요금(기준선) + 연간_가스요금(기준선)
```

## C. 신재생 전력 생산 → 전력요금 절감

### C-1. 태양광
```
일간_발전량 (kWh) = 태양광_용량(kW) × 태양광_일간발전시간(h)
월간_발전량 (kWh) = 일간_발전량 × 달력일수[월]
   · 달력일수[월] = 월별가동일라이브러리["365일가동"].월별가동일[월]  (= 31,28,31,...)
연간_발전량 (kWh) = Σ(1~12월) 월간_발전량
태양광_전력요금절감 (원) = Σ(1~12월) 월간_발전량 × 전기요금라이브러리.데이터[월].최대부하
```
> 태양광은 매일 발전하므로 가동일이 아닌 **달력일수** 사용. 단가는 사용자 지정대로 **최대부하단가** 기준.

### C-2. 연료전지 발전수익
```
연료전지_발전수익(연간) = F의 발전_연간총수익      (F 참조)
```

### 전력요금 절감 합계
```
전력요금_절감합계 = 태양광_전력요금절감 + 연료전지_발전수익
```

## D. 신재생 열 생산 → 가스요금 절감 (전력과 별도 산출)
```
연료전지_열생산수익(연간)   = F의 열생산_연간총수익      (F 참조)
연료전지_도시가스사용요금   = F의 연간_도시가스사용요금   (F 참조)
가스요금_절감합계 = 연료전지_열생산수익 − 연료전지_도시가스사용요금
```

---

## E. 최종 — 신재생 도입 효과
```
연간_총절감액 = 전력요금_절감합계 + 가스요금_절감합계
전력_절감률 (%) = 전력요금_절감합계 / 연간_전기요금(기준선) × 100
가스_절감률 (%) = 가스요금_절감합계 / 연간_가스요금(기준선) × 100
총_절감률 (%)   = 연간_총절감액 / 연간_총에너지요금(기준선) × 100
```
> 화면에는 전기·가스 기준선과 각각의 절감을 **분리 표시**하고, 총 에너지요금·총 절감액·총 절감률을 함께 보여준다.

## F. (재사용) 연료전지 산출 — output1 / output2 형식

> 입력: Input1_연료전지정보(sets[]), Input2_운전시간정보(연간운전유형, 일일_중간부하_운전시간=18, 일일_최대부하_운전시간=6)
> 라이브러리: 연료전지제품라이브러리, 가스요금라이브러리, 월별가동일라이브러리
> 전기요금: **시간대별 요금제(일반용 을)의 월별 중간부하·최대부하 단가** 사용 (이전 앱과 동일). 건물 기준선(B)이 갑이어도 연료전지 발전수익은 을 시간대 단가로 산정 — 이전 앱 결과 일치를 위함(추후 통일 검토).

```
총설치용량_kW = Σ(sets[i].정격발전용량_kW × sets[i].설치수량)
월별가동일[월] = 월별가동일라이브러리[연간운전유형].월별가동일[월]

[output1 — 월별 생산량/사용량]
월간_중간부하시간_전력생산_kWh = 총설치용량_kW × 일일_중간부하_운전시간 × 월별가동일[월]
월간_최대부하시간_전력생산_kWh = 총설치용량_kW × 일일_최대부하_운전시간 × 월별가동일[월]
월간_연료전지_열생산_kWh = Σ(열생산용량_kW × 설치수량) × (중간부하시간 + 최대부하시간) × 월별가동일[월]
월간_도시가스사용_kWh   = Σ(가스소비량_kW × 설치수량) × (중간부하시간 + 최대부하시간) × 월별가동일[월]
   · 열생산용량_kW 가 null 인 세트는 0 으로 처리

[output2 — 월별 수익]
발전_월간총수익 = ( 총설치용량_kW × 기본요금_원per_kW
                + 월간_중간부하시간_전력생산 × 데이터[월].중간부하
                + 월간_최대부하시간_전력생산 × 데이터[월].최대부하 ) × 1.1 × 1.032
열생산_월간총수익 = 월간_연료전지_열생산 × 가스요금["일반용(영업1) 도시가스 요금"].단가_원per_kW
도시가스사용요금  = 월간_도시가스사용 × 가스요금["연료전지전용"].단가_원per_kW
에너지생산_최종수익(월) = 발전_월간총수익 + 열생산_월간총수익 − 도시가스사용요금

[연간 합계]
발전_연간총수익     = Σ 발전_월간총수익
열생산_연간총수익   = Σ 열생산_월간총수익
연간_도시가스사용요금 = Σ 도시가스사용요금
```

## G. 경제성 평가 — output3 / output4 형식

### G-1. 추가 입력 / 비용
```
초기투자비용 = 태양광_용량 × 태양광_kW당설치단가
            + Σ(sets[i].정격발전용량_kW × 설치수량 × kW당설치단가)
연간유지보수비용 = 태양광_용량 × 태양광_kW당유지비
              + Σ(sets[i].정격발전용량_kW × 설치수량 × kW당연간유지비용)
연간편익(총수익) = 연간_총절감액      ← E
```

### G-2. 연도별 현금흐름 (output3, 연도 0 .. 분석기간)
```
순현금흐름[0]     = − 초기투자비용
순현금흐름[n]     = 총수익 − 연간유지보수비용            (n ≥ 1)
누적순현금흐름[n]  = Σ(k=0..n) 순현금흐름[k]
할인순현금흐름[n]  = 순현금흐름[n] / (1 + 할인율)^n
```

### G-3. 최종 평가 (output4, 기간 = 5/10/15/20년)
```
누적수익            = 총수익 × 기간
누적유지보수비용     = 연간유지보수비용 × 기간
총비용              = 초기투자비용 + 누적유지보수비용
ROI_초기투자        = (누적수익 − 총비용) / 초기투자비용 × 100   (이전 앱 정의 확인)
ROI_총비용          = (누적수익 − 총비용) / 총비용 × 100        (이전 앱 정의 확인)
NPV(기간)           = Σ(n=0..기간) 할인순현금흐름[n]
IRR                 = NPV = 0 이 되는 할인율 (이분법/뉴턴법)
단순투자회수기간     = 누적순현금흐름[n] ≥ 0 되는 최초 연도 n
B/C                 = Σ 편익현재가치 / Σ 비용현재가치
```
